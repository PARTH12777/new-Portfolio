# 🚀 Quick Start - See Your Portfolio in Action!

## ⚡ **Instant Setup (3 Steps)**

### 1. **Install Dependencies**
```bash
npm install
```

### 2. **Set Up Email (Optional for testing)**
```bash
# Copy environment template
cp .env.example .env

# Edit with your Gmail credentials (optional for now)
# EMAIL_USER=patidarparth2660@gmail.com
# EMAIL_PASS=your-gmail-app-password
```

### 3. **Launch Portfolio**
```bash
npm start
# OR use the startup script
./start.sh
```

**🌐 Open:** `http://localhost:3000` in your browser

## 🚨 **Troubleshooting**

### **Port Already in Use?**
```bash
# Kill existing process
pkill -f "node server.js"
# Or use different port
PORT=3001 npm start
```

### **Dependencies Issues?**
```bash
# Clean install
rm -rf node_modules package-lock.json
npm install
```

### **Email Not Working?**
- Portfolio works without email setup
- Only contact form needs Gmail configuration
- See DEPLOYMENT.md for email setup guide
