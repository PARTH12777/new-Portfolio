## 📧 **Email System in Action**

When someone submits the contact form:

1. **User fills form** → Validates inputs
2. **Sends to backend** → Rate limiting applied
3. **Email sent to** `patidarparth2660@gmail.com` with beautiful HTML template
4. **Auto-reply sent** to user with styled confirmation
5. **Success notification** appears with green checkmark
6. **Form resets** for next submission
